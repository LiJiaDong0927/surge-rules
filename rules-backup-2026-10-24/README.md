# Surge Rule 原文备份（2026-10-24）

这里保存备份时当前生效 Surge 配置引用的全部 **63 份远程规则名单**，共 1,334,014 字节。每份名单按原始字节保存，包括注释、换行、规则顺序和已有 `no-resolve`，没有改写、排序或合并。

本次只新增本目录：**没有更改 Surge 配置中的任何地址、DNS 或分流规则，也没有覆盖仓库中已有文件。** `LAN`、`GEOIP` 等非 URL 规则没有可下载的远程文件，不计入这 63 份。

## 来源与校验

- [sources.csv](sources.csv)：文件名、原地址、备份 Raw 地址、SHA-256 和字节数对照，可用表格软件打开。
- [manifest.json](manifest.json)：完整来源、获取时间、下载方式、SHA-256、Git blob SHA 和文件大小。
- 59 份名单从配置里的 `ghfast.top` 原地址获取；其实际 GitHub 上游地址另存于 manifest，不以直接上游内容替换镜像内容。
- 4 份来自本仓库原有文件，按原 Git blob 复制并核对哈希；根目录原文件仍保留。

这是备份时原地址返回内容的独立快照，不是 Surge 历史缓存导出。文件保留各自原作者的署名、注释及适用许可，来源见对照表。本目录不自动跟随上游变更。

## 使用方式

现有 Surge 配置继续使用原地址。仅将这些文件保存到 GitHub，不会改变当前分流或 DNS 行为。

将来如果需要切换到本目录的地址，可从 `sources.csv` 取得对应的 `backup_raw_url`，一次只替换相应规则的 URL；策略组、顺序、`no-resolve` 等参数须保留，并在备份及校验后重新载入。没有明确需要时，无须修改当前配置。

后续制作新快照建议另建日期目录，保留本次文件；即使上游删除，已保存的本次快照也不会自动被清空。
